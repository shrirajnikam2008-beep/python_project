1. The Big Picture: How Waypoint Works

If Waypoint were a world-class restaurant:

  • frontend/ is the Dining Room: The beautiful menus, tables, lighting, and buttons that the customer sees, clicks, and touches.
  • backend/ is the Kitchen: The chefs, ovens, and algorithms doing the heavy math, graph calculations, and AI logic behind closed doors.

5. Core Engineering Principles Explained

1. Prerequisite Graph as a DAG (Directed Acyclic Graph)

A skill roadmap is not a simple linear list. Because some skills can be learned in parallel while others have strict dependencies, Waypoint models learning paths as a Directed Acyclic Graph (DAG):

  • Directed: Edges have arrows indicating dependency (e.g. Python → Machine Learning).
  • Acyclic: There are no infinite circular dependencies (you cannot have A depend on B, B depend on C, and C depend on A).
  • Topological Sorting: An algorithm that arranges skills in an order where all prerequisites are satisfied before subsequent skills begin.

2. Deterministic Accuracy First, AI Explanations Second

Many modern apps make the mistake of asking an LLM to "invent" a career roadmap, leading to hallucinations. Waypoint uses a hybrid design:

  • The Math is Deterministic: The skill gaps, prerequisite order, and timelines are calculated mathematically in Python using graph theory and set operations.
  • The AI is an Explainer: The Gemini LLM is provided the already-calculated results and simply explains them in encouraging, easy-to-understand language.

3. The API Abstraction Layer Pattern

In frontend/lib/api.ts, the frontend UI never calls raw HTTP URLs directly. Instead, UI components call functions like getRouteGraph(id). This separation means the frontend can run seamlessly with mock data during UI development, and later connect to live FastAPI endpoints without changing a single line of component code.

6. Recommended Learning Roadmap (How to Build This Yourself)

If you want to master the skills needed to build platforms like Waypoint, follow this 4-phase learning progression:

Phase 1: Modern Web UI & TypeScript
1. React Fundamentals: Components, props, useState, and useEffect.
2. TypeScript: Type annotations, interfaces, and union types.
3. Next.js 14 App Router: Server vs. client components, page routing, layouts.
4. Tailwind CSS: Flexbox, CSS Grid, responsive design modifiers.
Phase 2: Graph Visualization
1. React Flow: Canvas setup, node positioning, edge styling.
2. Custom Nodes: Building custom node components with Handles.
3. Stateful Graph Interactions: Click handlers, zoom controls, and flyout detail panels.
4. Framer Motion: Smooth UI transitions and animated indicators.
Phase 3: Python Backend & APIs
1. FastAPI: Creating endpoints (GET, POST), path/query parameters.
2. Pydantic v2: Validating input/output data schemas.
3. Pandas & CSVs: Filtering, merging, and querying tabular datasets.
4. CORS & HTTP: Connecting frontend client requests to backend servers.
Phase 4: Algorithms, ML & Generative AI
1. Graph Algorithms: Adjacency lists, DAGs, and Topological Sorting.
2. Scikit-learn: Vectorization and K-Means clustering for trajectory analysis.
3. Prompt Engineering: Feeding structured data into the Google Gemini API to produce explainable AI summaries.
