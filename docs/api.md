# Waypoint API Specification

## Endpoints

- `GET /health`: Health status.
- `POST /api/profile`: Create/update student profile.
- `POST /api/skill-gap`: Calculate skill gaps for a destination.
- `POST /api/routes`: Generate candidate learning routes.
- `GET /api/market-weather`: Get market signals for skills.
- `GET /api/opportunities`: Get matched scholarships and internships.
